# mookata-pos

ระบบสั่งอาหารผ่าน QR สำหรับร้านหมูกะทะริมน้ำ · React + Vite + Supabase

## หน้าในระบบ
| เส้นทาง | ใช้ทำอะไร | สถานะ |
|---|---|---|
| `/t/<qr_code>` | หน้าลูกค้า: ใส่รหัสโต๊ะ ดูเมนู ใส่ตะกร้า สั่ง ติดตามสถานะ ขอเปลี่ยนกระทะ/เช็คบิล | เสร็จ |
| `/admin/tables` | แคชเชียร์: เปิดโต๊ะ (ได้รหัส 4 หลัก) ดูออเดอร์ ปิดบิล เงินสด/พร้อมเพย์ | เสร็จ |
| `/admin/kitchen` | ครัว: คิวออเดอร์เรียลไทม์ เปลี่ยนสถานะ คำขอจากโต๊ะ เสียงเตือน | เสร็จ |
| `/admin/menu` | เมนู รูป สูตร ต้นทุนต่อจาน ราคาวัตถุดิบ ของหมด | เสร็จ |
| `/admin/report` | ยอดวัน ต้นทุน กำไร ค่าใช้จ่าย สต็อก ของเสีย รายการซื้อพรุ่งนี้ (เจ้าของร้าน) | เสร็จ |
| `/admin/settings` | ข้อมูลร้าน พร้อมเพย์ พนักงาน โต๊ะ พิมพ์ QR | เสร็จ |

## เริ่มใช้งานครั้งแรก
เข้าระบบหลังร้านด้วย **ชื่อผู้ใช้ + รหัสผ่าน** (ไม่ต้องใช้อีเมล) เว็บไม่มีปุ่มสมัคร
1. Supabase → Authentication → Sign In / Providers → ปิด "Allow new users to sign up"
2. Supabase → SQL Editor → วางไฟล์ `supabase/migrations/20261006_username_login.sql` → Run
   และวางไฟล์ `supabase/migrations/20261006_beer_promo.sql` → Run (แยกโปรเบียร์ออกจากเซ็ตหมูกะทะ)
   และวางไฟล์ `supabase/migrations/20261006_beer_pricing.sql` → Run (เบียร์ลีโอ/สิงห์รายขวด + ต้นทุนโปรเบียร์)
3. เข้า `/admin` ด้วย **admin / 123456** แล้วกด 🔑 เปลี่ยนรหัส ทันที
4. ตั้งค่า → ใส่เลขพร้อมเพย์
5. พนักงาน: เจ้าของร้านสร้างบัญชีได้ที่ ตั้งค่า → พนักงาน (ชื่อผู้ใช้ + รหัส) และกด "ตั้งรหัสใหม่" ได้ถ้าพนักงานลืมรหัส

> ชื่อผู้ใช้เก็บใน Supabase Auth เป็น `<username>@mookata.local` บัญชีอีเมลเดิมยังพิมพ์อีเมลเต็มเข้าระบบได้เหมือนเดิม

## รันในเครื่อง
```
npm install
cp .env.example .env
npm run dev
```

## Deploy บน Vercel
1. Import repo นี้ใน Vercel (Framework: Vite)
2. Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` (ค่าตาม `.env.example`)
3. Deploy · `vercel.json` ตั้ง rewrite ให้ทุกเส้นทางเปิดได้แล้ว

## QR ประจำโต๊ะ
ลิงก์ของแต่ละโต๊ะคือ `https://<โดเมน>/t/<qr_code>` ดู `qr_code` ได้ในตาราง `dining_tables`

## รูปเมนู
เมนูที่ยังไม่มีรูปถ่ายจะแสดงรูปวาดของร้านอัตโนมัติ (เลือกจากชื่อเมนู เช่น สามชั้น หมึก เบียร์ น้ำแข็ง) ดู `src/components/Food.tsx` อัปรูปจริงในหน้าเมนูเมื่อไหร่ รูปจริงจะแทนที่ทันที

> ใช้แค่ publishable key ในหน้าเว็บ ห้ามใส่ service_role key ในโค้ดนี้
